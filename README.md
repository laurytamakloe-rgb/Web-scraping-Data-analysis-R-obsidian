#  Automatisation de Collecte et Analyse de Données (Web Scraping / API)

##  À propos de ce projet
Ce projet analytique a été réalisé dans le cadre de ma formation à la **Saint-Étienne School of Economics (SE²)**. 
L'objectif est d'automatiser l'extraction de données depuis le web via des APIs, de nettoyer et structurer ces informations brutes, puis de produire une analyse documentée.

##  Technologies et Outils
* **Langage :** R
* **Collecte de données :** Requêtes API et Web Scraping 
* **Manipulation de données (Data Wrangling) :** Tidyverse (`dplyr`, `tidyr`)
* **Documentation & Reporting :** Obsidian (Markdown) pour la rédaction du rapport d'analyse et la structuration des connaissances.

## Fonctionnalités principales
1. **Extraction automatisée :** Création de scripts pour interroger des APIs publiques et extraire des données.
2. **Nettoyage et Structuration :** Traitement des valeurs manquantes, formatage des types de données et jointures de tables.
3. **Analyse Exploratoire :** Calcul de statistiques descriptives et mise en évidence des tendances clés.
4. **Reporting Technique :** Rédaction d'un rapport analytique complet et structuré sous Obsidian, exploitant le format Markdown pour une documentation claire et interconnectée.
