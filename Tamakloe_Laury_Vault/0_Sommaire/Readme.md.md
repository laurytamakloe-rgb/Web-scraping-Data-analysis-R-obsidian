## 🎯 Problématique

"Comment concilier mon attrait pour les mathématiques et les sciences économiques au sein d'un métier d'avenir ?". Ce projet explore deux voies : **l'Actuariat** et **l'Enseignement-Recherche**.

Une attention particulière est portée à la **fiabilité des données salariales** en comparant les sources institutionnelles (ONISEP, CIDJ) et les réalités du terrain (Mazars, UJM).

## 🛠️ Points Techniques Clés

Ce Vault démontre l'utilisation d'outils numériques avancés pour l'analyse de données:

- **Dataview** : Automatisation des tableaux comparatifs de salaires à partir de propriétés YAML.

- **Webscraping (R)** : Collecte de données automatisée via les bibliothèques `rvest` et `pdftools`.

- **Visualisation** : Utilisation de **Canvas** pour modéliser le réseau de compétences et de **Excalidraw** pour les schémas.

- **Esthétique** : Personnalisation via un fichier CSS dédié pour améliorer la lisibilité.


---

## 🏁 Conclusion du Projet

Après analyse, mon choix se porte sur l'**Actuariat**. Ce métier répond à mes besoins de stimulation intellectuelle et de réalisation de soi, tout en offrant une insertion professionnelle dynamique après un Bac+5.
